Обучение WB ПВЗ by @edholod — обновлённая версия Telegram Mini App.

Состав: index.html, style.css, content.js, app.js.
Возможности: 76 уроков, 39 тестовых вопросов, поиск по тексту, 14 рабочих сценариев, тестирование, прогресс и избранное (сохраняются локально в браузере), адаптивный дизайн.

Публикация на GitHub Pages:
1. Создайте новый публичный репозиторий GitHub или используйте отдельный репозиторий для обучения.
2. Загрузите ВСЕ четыре файла из архива в корень репозитория (не сам ZIP).
3. Settings → Pages → Deploy from a branch → main / (root) → Save.
4. Откройте адрес https://ВАШ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/ и проверьте приложение.
5. Добавьте этот HTTPS-адрес в WebApp-URL кнопку Telegram-бота.

Важно: приложение не подключено к API Wildberries, не может проверять текущие статусы или автоматически обновлять оферту. Инструкции собраны из предоставленных материалов разных дат; актуальные правила проверяйте в https://t.me/edholod_wbbot.
Оригинальные PDF и ссылки на них в приложении отсутствуют.
